# PROBLEM SPECIFICATIONS
- **Target URL:** `https://ok.ru/video/248244667877`
- **Target Dialogue:** "My mind rebels at stagnation"
- **Required Outputs:** A saved PNG image of the exact frame, and a JSON manifest containing the timestamp (HH:MM:SS.sss), frame number, extracted text, and confidence score.

# PIPELINE ARCHITECTURE (The Multi-Modal Funnel)
You must implement a multi-modal coarse-to-fine search pipeline. **DO NOT use any Vision-Language Models (VLMs) or LLMs for image processing.** Rely strictly on Audio ASR and visual OCR. 

Implement the following phases in `src/find_dialogue.py`:

1. **Phase 0: Ingestion & Probing**
   - Use `yt-dlp` to download the video locally. Ensure you handle `ok.ru` compatibility.
   - Use `ffmpeg` / `ffprobe` to extract video metadata: `fps`, `duration`, `resolution`.
   - Extract the audio track as a 16 kHz mono WAV file.

2. **Phase 1: ASR Accelerator (The Fast Pass)**
   - Run `faster-whisper` on the extracted audio.
   - Perform a fuzzy string search (using `rapidfuzz`) on the transcript for the target dialogue. 
   - *If found:* Set a narrowed OCR search window of `[t_spoke - 2.0s, t_spoke + 2.0s]`.
   - *If NOT found (Handling Visual-Only Text):* Set the search window to the full video duration `[0, duration]`.

3. **Phase 2: Coarse Sampled OCR**
   - Using `opencv`, sample the video at **1 frame per second (1 fps)** strictly within the search window defined in Phase 1.
   - Use `PaddleOCR` (or `EasyOCR` if Paddle is unavailable in your environment) to extract text from these sampled frames.
   - Use `rapidfuzz` (`token_set_ratio`) to compare the extracted text against the target string.
   - **Confidence Scoring:** Score >= 85 is a confirmed match (OK). Score between 70 and 84 is LOW_CONFIDENCE. Score < 70 is NOT_FOUND.

4. **Phase 3: Coarse-to-Fine Temporal Refinement**
   - Once a coarse match >= 70 is found at timestamp t_max, execute a multi-pass temporal binary search to find the *exact first frame*.
   - **Pass A:** Step backwards/forwards at 0.1s granularity within `[t_max - 1.0s, t_max + 1.0s]`.
   - **Pass B:** Step at 0.01s granularity around the new best match.
   - **Pass C:** Step frame-by-frame (`1/fps`) to lock in the exact first appearance frame.

5. **Phase 4: Output Generation**
   - Calculate exact frame index: `frame_num = int(timestamp * fps)`.
   - Save the exact frame as `output_frame.png` in full resolution.
   - Generate `manifest.json` containing the timestamp, frame number, extracted text, and confidence status.
